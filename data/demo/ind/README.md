# inD Demo/Test Subset

This directory contains the small inD excerpt used for repository smoke tests.
It is intentionally much smaller than a full inD recording.

## Contents

- `raw/`: inD-format CSV files from recording `04`, frames `2028` to `3027`,
  after keeping assigned vehicle tracks that are long enough for 12-step windows.
- `assignments/`: matching reference-path assignment filter for the retained
  tracks.
- `processed/`: compressed state/action NPZ shards generated by
  `scripts/datasets/ind/build_ind_demo.py`.
- `expected_outputs/`: JSON summaries used to check the demo preprocessing
  result.

## Demo Build

```bash
python scripts/datasets/ind/build_ind_demo.py \
  --config configs/datasets/ind_demo.yaml \
  --clean
```

Expected preprocessing result:

- raw trajectory rows: `1,929`
- retained tracks: `13`
- processed state/action samples: `153`
- split counts: train `106`, validation `26`, test `21`
- state shape: `[N, 12, 12]`
- action shape: `[N, 2]`
- directory size: about `444 KB`; no single file is larger than `1 MB`

For full-scale experiments, update `configs/datasets/ind.yaml` or a separate
local config file with local inD paths.
