# Visualization Scripts

`plot_longtail_case_demo.R` writes the three Appendix long-tail qualitative case
PDFs from `data/demo/longtail_cases/`.

Run from the repository root:

```bash
Rscript code/scripts/visualization/plot_longtail_case_demo.R
```

Optional environment variables:

```text
LONGTAIL_CASE_DEMO_DATA_DIR   Override the input data directory.
LONGTAIL_CASE_DEMO_OUT_DIR    Override the output directory.
```

Default output is written to `code/artifacts/longtail_case_demo/`.
