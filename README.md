# Human-inspired Data-light Cultural Alignment

This repository contains the code and small demo data release for the paper
"Human-inspired Data-light Cultural Alignment for Cross-regional Deployment of
Autonomous Vehicles".

## Structure

```text
code/      Source code, configs, scripts, checkpoints, and detailed instructions.
data/      Small released demo inputs and expected outputs.
results/   Reproducible-run outputs generated by the demo scripts.
```

Detailed installation, demo, evaluation, and full-data reproduction instructions
are in `code/INSTRUCTIONS.md`.

## Quick Demo

```bash
bash code/scripts/run_release_demo.sh
```

The demo writes training outputs, evaluation summaries, and Appendix long-tail
case PDFs under the repository-root `results/` directory.
