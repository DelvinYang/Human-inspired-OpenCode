# Scripts

Script directories are scaffolded by role and dataset.

- `datasets/ind/`: inD demo and full-data preprocessing entry points.
- `datasets/highd/`, `datasets/ngsim/`, `datasets/sind/`, `datasets/citysim/`,
  `datasets/dji/`: script-only support for users with local dataset access.
- `experiments/`: training and transfer experiment launchers.
- `evaluation/`: metric and table-generation entry points.

Implementation files will be added after the release skeleton is approved.
